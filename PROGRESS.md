Шрифт — Manrope (обычное начертание, без капса/агрессивной типографики). Анимация сведена к минимуму — только лёгкое fade-in при скролле (`IntersectionObserver`, без GSAP/glow/marquee/пульсаций) — в брифе прямо указано «не нравится перегруженный дизайн, много анимации, движущиеся элементы».
- **Структура и тексты — по брифу дословно/близко к тексту**:
  - Hero: «Надёжный поставщик топлива в Шымкенте и Туркестанской области», статы 25+ лет / 3 АЗС / 4.8 (2ГИС)

## Ключевые решения (и почему)
- Бриф — приоритетный источник правды. Он полностью заменил все предыдущие цветовые/стилистические эксперименты этой сессии (см. архив ниже) — как только пришёл официальный документ, поехали по нему, а не по более ранним прикидкам.
- Год основания 1998 (по брифу) vs 2001 (по statsnet) — заказчик явно выбрал версию брифа. Причина расхождения не выясняли (не наша зона ответственности), но если позже уточнят — легко поменять во всех местах (hero, «О компании», FAQ).
- Не стали копировать фото/дизайн с royal-petrol.kz — это реальный конкурент, использовали только структурную логику, которую заказчик прямо запросил.
- Реальные телефоны и 3 адреса АЗС — впервые появились в брифе, добавлены как есть, без изменений.
- Логотип не рисовали «от себя» — заказчик прислал не сам логотип, а описание («есть, но не в векторе»); рисовать чужой логотип по одному текстовому упоминанию нельзя, ждём файл.

## Архив: эксперименты до получения брифа (уже не актуальны на сайте)
Более ранние версии сессии перебирали несколько дизайн-направлений по ходу разговора (до того, как заказчик прислал официальный бриф): индустриальный серый+оранжевый → «21st.dev»-стиль (glassmorphism, тёмная тема) → зелёная палитра (по референсу oml.ru) → айдентика BMW M (чёрный/синий/фиолетовый/красный, по прямой просьбе заказчика, шрифт Barlow Condensed). Ни одно из этих направлений не сохранилось — актуальный дизайн полностью заменён версией по брифу (светлая корпоративная тема, navy+жёлтый+зелёный). Упоминаю только для истории — не переносить старые решения обратно без явного запроса.
