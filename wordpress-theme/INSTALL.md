# АЗК Алмаз — тема WordPress

Механический перенос утверждённого статического сайта (`index.html` в корне проекта) в тему WordPress + ACF Pro. Дизайн, вёрстка и контент — 1:1. Без ACF Pro (или до заполнения полей) тема рендерит тот же контент из значений по умолчанию — сайт выглядит идентично сразу после активации.

## Что внутри
```
azk-almaz/                  ← сама тема (её и загружать/зиповать)
  style.css                 ← заголовок темы
  functions.php             ← подключение стилей/скриптов (Tailwind CDN, Lucide CDN, Google Fonts)
  header.php / footer.php   ← шапка, подвал, модальное окно политики/оферты
  front-page.php            ← сборка всей посадочной из template-parts
  index.php                 ← fallback для прочих URL
  template-parts/           ← по одному файлу на секцию (hero, advantages, about, products, services,
                               timeline, azs, promo, faq, contacts, policy-modal)
  inc/helpers.php           ← безопасное чтение ACF-полей с дефолтами (azk_field/azk_sub/azk_setting)
  inc/defaults.php          ← контент по умолчанию — 1:1 с утверждённой статикой
  inc/acf-fields.php        ← поля ACF Pro (Options Page + поля главной страницы + правовые тексты)
  assets/                   ← css, js, фото (hero-depot.jpg, about-gas-station.jpg, fleet.jpg, lab.jpg, canopy.jpg)
```

## Требования
- WordPress 6.0+
- PHP 7.4+
- **ACF Pro** — обязателен для полноценного редактирования (Repeater, Options Page). Без него сайт работает, но карточки/настройки не редактируются через админку — только через `inc/defaults.php` в коде.

## Установка (чистый WordPress)
1. Установить и активировать **ACF Pro** (лицензия).
2. Appearance → Themes → Add New → Upload → загрузить `azk-almaz.zip`, активировать.
3. Создать страницу (например «Главная»), опубликовать.
4. Settings → Reading → «На главной странице отображать» → Статическую страницу → выбрать «Главная».
   (Специально настраивать Page Attributes → Template не нужно — `front-page.php` подключается автоматически для страницы, назначенной главной.)
5. Settings → Permalinks → выбрать любой вариант, кроме «Обычные» (`/%postname%/` — как на сайте-доноре).
6. Заполнить ACF-поля на странице «Главная» (все поля уже показывают значения по умолчанию — их можно просто поправить) и на странице «Настройки сайта» (телефоны, адрес, БИН, часы работы).

Эти значения используются в шапке, подвале и разделе «Контакты».
  - Компания — **ТОО «АЗК Алмаз»**, АЗС сети — бренд **ALMAZ** (латиницей) — эти два названия используются в разных местах намеренно, не унифицировать.
- **Страница «Главная»** (вкладки в блоке ACF): Hero, Преимущества, О компании (принципы, фото-вкладки, статистика), Продукция (карточки топлива со спецификациями, характеристиками и ценой/плотностью для калькулятора), Услуги, Схема сотрудничества, Сеть АЗС (список станций с адресом, координатами метки на карте, топливом и удобствами), Акции, Вопросы (FAQ), Контакты (карточки телефонов).
- **Правовые документы**: отдельная группа полей с текстом «Политики конфиденциальности» и «Условий использования» (WYSIWYG) — показываются в модальном окне из подвала.

## Калькулятор оптовой стоимости
Цена за литр и плотность каждого вида топлива — это поля внутри карточки продукта (`price_per_liter`, `density`). Калькулятор на фронтенде считает по этим значениям в реальном времени (JS), без обращения к серверу — если изменить цену в ACF, калькулятор сразу пересчитывает по новой цене после сохранения страницы.

## Формы и заявки
На сайте **нет форм обратной связи** — все призывы к действию ведут на `tel:`-ссылки с реальными номерами телефонов компании. Это осознанное решение (см. историю проекта): раньше в макете были формы с фиктивной отправкой без реального приёма заявок — от них отказались в пользу прямых звонков.
